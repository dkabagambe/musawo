# LOAD RESULTS (remarks.md SECTION 5)

Status: NOT RUN YET. This file is generated by `npm run load:30` on first run.

## Target

30 users studying at the same time (reading materials, joining a live class,
taking an exam, posting, heartbeating) with no errors and quick pages. A second
run at 60 users checks headroom.

## How to run

```bash
npm run load:30
```

This one command:
1. Checks k6 is installed (prints the install command if not).
2. Starts a local production server if one is not already up at BASE_URL.
3. Discovers the seeded students, a PUBLISHED exam and a LIVE class from the
   database (runs `npm run db:seed-topup` once if the 30-student cohort or a
   LIVE class is missing).
4. Runs k6 at 30 users for 5 min, then 60 users.
5. Overwrites this file with per-step p50, p95, p99, error rate and 5xx counts
   plus a verdict against the targets (error rate under 1%, p95 under 1 s,
   login p95 under 2 s, no 5xx).

## Run against Render staging

```bash
BASE_URL=https://staging.example.org GATE_USER=demo GATE_PASSWORD=secret npm run load:30
```

Steps: login once per user, then dashboard, 3 materials pages, timetable,
forum post, live-class join request, and a presence heartbeat every ~30 s.
The first 10 users also take the exam (start, answer all questions in order,
submit). Video is handled by Google Meet (external); this test exercises only
the application server.
