📋 THE 5-PHASE MIGRATION
═══════════════════════════════════════════════════════════════════════════════

PHASE 1: CREATE SERVICES (20 min)
─────────────────────────────────
  1. Create Neon account (https://neon.tech)
     → Create PostgreSQL database
     → Copy pooler connection string

  2. Create Upstash account (https://upstash.com)
     → Create Redis database
     → Copy Redis URL

  3. Create Vercel account (https://vercel.com)
     → Sign in with GitHub
     → Done (don't import repo yet)

  Result: You have 3 connection strings ready

PHASE 2: BACKUP & RESTORE (15 min)
──────────────────────────────────
  1. Run: ./scripts/migrate-to-vercel.sh
  2. Paste connection strings when prompted
  3. Script exports Render database
  4. Script restores to Neon
  5. Script generates secrets in .env.vercel

  Result: Data is in Neon, secrets are generated

PHASE 3: DEPLOY TO VERCEL (25 min)
──────────────────────────────────
  1. Go to Vercel dashboard
  2. Import musawo GitHub repo
  3. Paste env vars from .env.vercel into Vercel Settings
  4. Click Deploy
  5. Wait 3-5 minutes for build

  Result: App running on Vercel at vercel.app domain

PHASE 4: TEST (10 min)
──────────────────────
  1. Visit your Vercel URL
  2. Log in → students can log in ✓
  3. View courses → data displays ✓
  4. Upload file → S3 integration works ✓
  5. Send email → Resend integration works ✓
  6. Try payment demo → Pesapal works ✓

  Result: Everything verified working

PHASE 5: FINAL CUTOVER (5 min — ONLY DOWNTIME)
───────────────────────────────────────────────
  1. Go to Render dashboard
  2. Find musawo-web service
  3. Click "Suspend"
  4. Done — app now 100% on Vercel

  Result: Old Render app offline, Vercel live
